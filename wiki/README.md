# Wiki source

User-facing documentation, staged in-tree and publishable to the GitHub
wiki (`ReWrite-OCR-Scanner.wiki.git`). Keep pages current in the same
change as the behavior they describe (`.docs-sync.json` enforces the
coupling); contributor-facing detail belongs in `docs/`, not here.
